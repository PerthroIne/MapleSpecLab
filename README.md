# MapleSpecLab · 메이플 키우기 스펙 연구소

![대표 이미지](./assets/brand/representative.png)

> **이 연구소는 개인의 호기심으로 시작한 개인 프로젝트입니다. 개인의 사정이나 변덕에 따라 연구소가 삭제되거나 추가 업데이트가 중단될 수 있습니다.**

스펙, 장비, 어빌리티, 동료 변경을 비교하고 적용 후 변화를 연구하는 로컬 우선 웹 도구입니다. 이미지 OCR이 기본이지만 모든 주요 입력은 직접 작성할 수 있습니다. v1.2.0부터 메이플 키우기 공식 가이드의 일반 피해 계산 순서를 피해 비교의 기본 모델로 적용합니다.

## 웹에서 사용하기

GitHub Pages가 설정된 뒤 아래 주소로 접속합니다.

`https://내아이디.github.io/저장소명/`

모바일에서는 브라우저 메뉴의 **홈 화면에 추가**를 이용하면 앱처럼 실행할 수 있습니다. PC에서도 같은 주소로 바로 사용할 수 있습니다.

## 기본 이용 순서

1. 현재 스펙을 이미지 OCR 또는 직접 입력으로 등록합니다.
2. 장비·어빌·동료의 변경 전 A와 변경 후 B를 입력합니다.
3. OCR 결과와 수치를 검토합니다.
4. `B - A` 변화량이 현재 스펙에 적용되는지 확인합니다.
5. 대상 방어력과 상태이상 조건을 선택하고 공식식 기준 피해 지수 변화를 확인합니다.

장비 입력은 **1-3번 주옵션 / 4-7번 부옵션**으로 구분되어 있습니다.

## 공식 정보와 비교 모델

능력치 정의, 누적 방식, 상한, 전투 규칙과 일반 피해 계산 순서는 [메이플 키우기 공식 가이드](https://maplestoryidle.nexon.com/ko/guide)를 우선 적용합니다. 가이드 2026-08-08 최신화본을 2026-08-08 확인했습니다.

공식 정보만으로 처리하기 어려운 기존 항목과 프로필 호환 부분은 [최종뎀 계산기 Beta 2.0](https://kimprincess-calculator.netlify.app/)을 보조 참고합니다. 대상 방어력은 선택 입력이며, 상태이상은 미적용·상시·횟수와 시간 기반 적용률을 지원합니다. 받는 피해 효과, 콘텐츠 보정, 스킬 계수 등 입력되지 않은 변수는 없는 것으로 계산하므로 공식 전투력 또는 실제 DPS를 보장하지 않습니다.
